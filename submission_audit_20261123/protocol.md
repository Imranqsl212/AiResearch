## Frozen classification
Require an explicit listing in the published resolved IDs. For positive attribution require the nonempty UTF-8 submission string in the trajectory metadata to be byte-identical (SHA-256) to the sole distinct prediction patch for the issue; repeated identical rows are permitted. Multiple distinct predictions, including an empty alternative, are ambiguous. Never normalize, guess a patch from a diff, or select a model-written passage as an action. Use the structured trajectory plus the non-demonstration assistant action history. Require a matching terminal action in the two records. A strict agent submission requires the terminal action to be the standalone submit command after trimming whitespace, with submitted exit status and the matching submitted patch. A strict automatic submission requires a terminal system exit action, a submitted exit status naming that same boundary, and an observation explicitly reporting autosubmission. Record reason separately (cost, context, other). Ambiguous or compound commands, contradictions, absent files, missing fields and byte mismatches remain unknown. A failed HTTP retrieval other than confirmed missing is a technical failure to retry, not proof of absence. Use official Verified trace objects; no issue replacement or alternative trial. Preserve row-level source URLs, hashes, action category, locators and reason; never store model reasoning or full patches in research outputs.
