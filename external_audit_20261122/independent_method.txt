3. Inspect the terminal trajectory action, its model-response field, environment
   observation, and /info/exit_status. A recorded submit plus matching submission
   acknowledgment supports agent_acknowledged. A synthetic exit_cost action,

   controller_boundary. A submitted(exit_cost) status is not an agent submit.
4. For OpenHands, inspect each assistant tool_call function and decoded argument
   object as data, matching tool observations by tool_call_id. Search narrow

   an assistant message. None establishes the causal end of the run. A command's

5. Distinguish what is observed from what a different logging mechanism could
   explain. Do not infer intent, giving up, patch quality, or causal stop from a

6. Freeze independent_checks.json and its SHA-256 receipt before examining

Meaning of fields
-----------------
explicit_finish=true: a model-issued instance-level terminal request is recorded.
explicit_finish=false: no such request appears in an internally consistent
  instance action stream reaching an explicit controller boundary. This is
  scoped to the public artifact; it is not a statement about unlogged events.
explicit_finish=null: the artifact cannot establish presence or absence for the
  complete run (missing artifact or unvalidated terminal coverage).
agent_acknowledged: explicit agent request with matching environment terminal
  acknowledgment.
controller_boundary: affirmative cost/timeout/error/controller evidence; an
  automatic submission is recorded separately as a wrapper action.
both: both supported mechanisms coexist; no selected record required this code.
unknown: the causal termination is unestablished.

outputs are intentionally omitted. File hashes permit comparison with retrieved
artifacts. Reproduction is an ordinary data-parsing action, not model inference.
