# Prospective v1: independent READY audit — 4 October 2026

## Decision

**Main study: NOT_READY.** This is an audit of the current evidence, not a prohibition on further excluded engineering pilots. The root [`experiment_manifest.json`](../experiment_manifest.json) is a draft, [`experiments/v1_collector.py`](../experiments/v1_collector.py) explicitly rejects `phase="main"`, and [`analysis/v1_pipeline.py`](../analysis/v1_pipeline.py) reports `NO_ELIGIBLE_DATA` with zero main manifests. Every live block described below is excluded.

The official Docker suite was rerun on 4 October 2026. Its [`latest_result.json`](../sandbox/safety_checks/latest_result.json), generated at `2026-10-04T06:50:12Z`, reports **11/11 checks PASS**, `overall_passed=true` and `experiment_permitted=true` for image `sha256:1c987bcba6e1e759fe257e929f50ced3b59933057043a8b0fecb020bccf501a9`, its recorded policy and Docker daemon. This includes an isolated Python candidate RPC path. Thus the current exact runtime safety check is cleared. A changed image, policy, daemon or main task path still requires a new official run and a manifest binding. Twenty finite families now have 100 checked C1–C5 rows: the original four have 1,430 cross-checks, batch A 140, batch B 90, and batch C 160. The [machine admission pre-review](../analysis/admission_review_20261004.json) has no artifact errors but explicitly records missing human review. The [SQLite v3 calibration](../benchmark/real_code_sqli_notes.md) and command-injection calibration add two real-code external-validity fixtures, but no agent-written repair. The historical catalog was not used as a substitute for these reviewed task artifacts.

The static [`reproduction/preflight.py`](../reproduction/preflight.py) exits 2 on the current draft. Its material failures include draft schema/status, missing model/runtime/retrieval/statistics values, eleven missing artifact digest/path bindings, no frozen source revision in the manifest, nine readiness flags still `NOT_READY`, and no manifest binding to the saved safety receipt. Source-tree cleanliness is checked at execution time. Passing this static script in the future is **necessary but insufficient**: it does not count families, independently grade oracle quality, verify mutation coverage, run a model, check real-code security, or assess statistical power. The analysis release gate additionally requires a pre-run lock, all scheduled slots, invalidation receipts, and a complete run receipt.

## Minimal honest path to READY

1. Independently review the four integrated finite mechanisms and use the completed excluded cross-model audit to repair protocol and provenance faults without contaminating a future main cohort.
2. Complete human admission review of all 20 mechanisms, broaden the executable-code tier, and freeze strong challenge sets and a mutation corpus. Reject families that fail proof, leak, parity or security checks rather than padding the count.
3. Freeze the model(s), retrieval corpus, prompts, task set, primary outcomes, contrasts, budget controls and all-slot schedule. Review the committed source revision, run the exact safety check, and complete an excluded end-to-end main-path rehearsal.
4. Populate the manifest only with evidence-backed `PASS` values, create the manifest-only freeze commit, and require both the static preflight and live pre-run gates to pass. **Only then** may a prospective main episode be eligible. The source and analysis gates must not be weakened to force READY.
5. Collect the prescheduled cohort, independently replicate on another model, complete blind coding, run the frozen analyses, release reviewed raw data and rewrite the paper from eligible results. These activities establish **result readiness**, which is later than **collection readiness**.

No current pilot result can replace a missing gate or be promoted to the prospective main cohort. If resources cannot support the requested 20-family repeated design, amend the scope **before** collection and report a narrower methodological study; keep the original broad empirical claims unmade.
