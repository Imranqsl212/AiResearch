# Следующие действия до READY — 8 октября 2026

## Текущее положение

Есть два разных результата. [Нынешняя статья](../paper/final.md) —
исследовательский аудит 40 исторических эпизодов с отдельно обозначенными
пилотами. Её [пакет для авторской проверки](../paper/AUTHOR_REVIEW_BUNDLE_20261005.md) сверен с
рабочими файлами, но имеет статус `REVIEW_ONLY`. Новый подтверждающий
эксперимент остаётся `NOT_READY`: [живой main-gate](../experiments/main_orchestrator.py)
возвращает 12 ложных проверок, 0 вызовов модели и 0 допущенных основных
эпизодов. Запуски из пилотов задним числом в основной набор не переводятся.

## Ближайший путь для подачи уже написанной статьи

1. **Завершить проверку данных для рецензентов.** [Независимый пересчёт](../paper/INDEPENDENT_DISCORDANCE_CHECK_20261008.md)
   подтвердил 9/20 расхождений из очищенных финальных квитанций без функций
   основного аналитического скрипта. Отдельная [проверка исходного архива](../paper/ORIGINAL_ARCHIVE_PROVENANCE_AUDIT_20261008.md)
   связала все 313 исходных файлов с очищенной копией и повторила результат
   9/20 из оригинальных записей. Это проверка локальных сохранённых байтов,
   а не исторического исполнения модели. Одна запись текущего реестра входных
   хешей уже отличается от архивной версии и должна быть явно отмечена при
   фиксации релиза. Закрытый
   [реестр приватности](SANITIZED_PRIVACY_REVIEW_REGISTER_20261008.md)
   содержит 465 адресованных находок в 42 группах; все решения проверяющего
   пока пусты. Нужно просмотреть контекст, выбрать исправления и затем
   пересобрать новую версию очищенного архива с повторным воспроизведением.
   Оригинальный архив сохраняется неизменным.
2. **Принять авторские решения.** [Форма](../paper/AUTHOR_SUBMISSION_DECISIONS_20261005.md)
   ждёт подтверждения вклада и текста, сведений о финансировании,
   конфликтах, благодарностях и AI-помощи, выбора журнала и реального способа
   доступа к данным. Содержательная помощь Codex теперь описана в Methods,
   но окончательную формулировку утверждает автор.
3. **Адаптировать и зафиксировать пакет.** После выбора журнала применить
   его формат, декларации и правила данных, проверить итоговый DOCX/PDF и
   анонимность, закрепить точную Git-ревизию и хеши рукописи, кода и доступного
   рецензентам архива. [SQJ](https://link.springer.com/journal/11219/submission-guidelines)
   сейчас содержит конфликт между специальным требованием `sn-jnl` LaTeX и
   общим разрешением Word; формат надо выяснить перед конвертацией.
   [EMSE](https://link.springer.com/journal/10664/submission-guidelines)
   принимает редактируемый DOCX или LaTeX и требует Data Availability
   Statement с действительным маршрутом доступа. Выбор журнала остаётся за
   автором; редакционная пригодность не гарантирована.
