## Design fixed before behavioral collection

Use the python-dateutil repeated-hour and CPython pretty-print ordering cases. Two CLI families, two tasks, two starting states and two matched repetitions give 16 blocks. Each block gets an early and a late arm, yielding 32 episodes and 64 scheduled decisions. First choice of families is GPT-6.2 Astra (low effort) and Claude Sonnet (subscription default). Before dispatch, run task-free access probes. Give both arms the same task, code, legacy failure, code-edit menu and two decision slots. Apply the first choice, including keeping the current source. In the early arm show the semantic observation before this choice. In the late arm withhold it until after this choice. Both arms then have the original observation, initial and current code, the first choice and one final opportunity to keep or revise. Never generate a fresh observation of the edited code as a substitute for the initial observation. Each CLI request runs in a fresh directory with no tools. Use the same decision menu order and neutral IDs within a matched block. Counterbalance timing order between the two repetitions; interleave blocks by a fixed random seed (20261126). Only one cloud client runs at once. No local model inference.

## Outcomes

The primary endpoints are a wrong-to-correct first decision on a genuinely defective start (repair) and a correct-to-wrong first decision on a correct start (damage), scored on held-out behavior. Keeping an already correct implementation and editing it to another correct implementation are both preservation. An edit alone is insufficient to infer damage. Measure terminal repair and damage after the second fixed decision separately, plus reversals after evidence arrives. Keeping the code does not terminate these two-slot episodes. They do not measure voluntary stopping, security, or unconstrained patch generation.

Show counts and denominators for each model, task, starting state and timing. Match early and late within model, task, state and repeat. Report paired discordance, missingness and the exact cases behind a difference. For identical endpoints on two independent samples, outcomes can still differ due to sampling.
