# Expanded-domain sensitivity for the two QuixBugs expression studies

This is an offline follow-up after the 48 original free-expression decisions were observed, and before collecting any target-reversal responses. Fix the additional domains, oracles and scorer before the first target-reversal response. For every available program, grade both candidate conventions on new cases and compare with its original grade. Report by experiment and condition, including every unscored scheduled row. Different model decisions that select the same expression do not create additional independent programs. This check detects a failing transfer if an expression passes all its original inputs for a given target and fails any expanded input for that target. Report its first witness input, expected and observed return.

- Maximum-sublist sum and quicksort: all nonempty sequences of lengths 1 through 6 over −7, −1, 2, and 5, 5,460 sequences for each task. This changes the alphabet and includes longer lists, repeated values and mixed signs.
- Balanced parentheses: all strings of lengths 6 through 10, excluding the two already displayed executions, 1,982 strings. This includes both deep nesting and strings that first fail late.
- Knapsack: capacities 1 through 9 with every ordered inventory of one through four items over (weight,value) pairs (1,6), (2,1), (3,6), (5,8), 3,060 instances. Repeated weights and different values test the strict versus inclusive capacity boundary.

These cases exclude every prior scored and displayed input for its task. Interpret both specifications with the independently written oracles and score using the same bounded source interpreter. Output independent native decisions and unique selected syntax separately. The additional domains deliberately shift inputs and emphasize longer structures. Uniform weighting over these sets is an analysis choice rather than a workload estimate. Passing both domains supplies bounded transfer evidence; it cannot establish correctness of a general program.

## How often does a random trusted example identify the rule?

Assume exactly two deterministic candidate rules with equal prior probabilities, and that an ideal decision rule knows both and can select a program realizing either one. Draw k inputs independently, with replacement, uniformly from the specified finite domain and independently of the hidden rule. On a fraction d of inputs their target outputs differ. If any observed target output distinguishes them, the ideal decision rule can attain correctness one. On the other event, the two rules retain equal probability. They disagree on at least one scored case, so any selected program can satisfy at most one target. The optimal probability of choosing the correct rule is therefore one minus half of (1 − d) to the kth power. This is a property of this design and these sampling assumptions, rather than a fit to agent decisions or a claim of a new general theorem. The study's distinguishing inputs were deliberately chosen. Include exact rational values for k = 0, 1, 3 and 5 in the released evidence.
