# Adversarial review of the prospective v1 study

**3 October 2026. Decision: reject any empirical paper claim today.** This review challenges the design and the engineering evidence. It is not a substitute for independent human review.

| Reviewer objection | Evidence now | Required resolution before the claim |
| --- | --- | --- |
| Small finite JSON policies are not real coding-agent security tasks. | Three different controlled mechanisms now pass saved proof validation, but only authorization v1 has a collector pilot. | Integrate the other schemas, add real-code tasks with independent adversarial evaluation, and treat the finite families as method checks only. |
| The oracle and reference checker could share an incorrect task fact. | Separate implementations agree on 40 authorization, 1,280 path, and 80 replay candidate/condition pairs, but each pair consumes shared authored task facts. | Independently review facts and threat models, mutate them deliberately, and compare with an external specification or human expert. Never call finite agreement general security. |
| The old unreachable-task result was defined by its condition label. | The old gate uses the label to veto acceptance. New C3/C4 have a contradictory-observation proof; C5 explicitly injects false rejection. | Keep old data in the audit appendix; require saved proof verification for every new task and never pool cohorts. |
| Weak tests may accept insecure policies. | The new C3/C4 common reference passes the three-state raw subset yet violates the fourth finite state. The old AEAD tamper check is broken. | Predeclare strong adversarial suites and insecure mutations for every real-code family. Report weak/strong/oracle confusion matrices with family-level uncertainty. |
| The retrieval condition changes context length and may leak the treatment. | R2 strips its `noise_injected` flag from agent-visible documents; exposure, rank, score and hashes remain in evaluator logs. Context lengths still differ. | Freeze a token-matched irrelevant-context control or predeclare length-adjusted contrasts. Audit every corpus document for exact task answers and record real model exposure. |
| The local model has not demonstrated reliable repair or evidence-based stopping. | A five-condition excluded block captured one C2 finite secure pass and one C4 voluntary stop with an action remaining, after two insecure submissions. Earlier protocol failures remain invalidated. | Repeat matched trajectories across tasks and models, check explicit claims and blinded stop explanations, and reserve main scheduling for a frozen design. |
| A claimed “stop after proof” may really be a timeout or parsing failure. | Collector distinguishes `VOLUNTARY`, `BUDGET`, `TIMEOUT`, `ERROR`, and checker pass; analysis excludes invalidated errors and records remaining budgets. | Blindly code the public explanation, retain competing stop causes, and show sensitivity to missing/invalidated slots. |
| Strategy change is being inferred from syntax or API names. | v1 codebook requires two blinded S0–S6 labels and preserves unassessable cases. No human labels exist. | Freeze the sample, obtain independent coders, report agreement, and withhold S3 rates until coverage is adequate. |
| Hash-linked local logs are not independently authenticated. | The old raw archive and engineering pilot manifests are now tracked in this local Git branch; a second scripted run matches deterministic fields. Remote availability must be verified separately. | Check the exact pushed revision, model snapshot/configuration, retrieval corpus, schedule, receipts, and a clean-room replay. Git presence and local hashes alone are not authentication or journal approval. |
| The planned 400+ episodes and cross-model replication are absent. | No v1 main episode exists; one small local model was found. | Validate at least 20 genuine matched families, repetitions, and more than one model before confirmatory inference, or narrow the paper to a methodological prototype. |

The strongest rejection reason is **external and construct validity**: finite fixtures demonstrate bounded feasibility and evaluator disagreement, but they do not show how real coding agents repair security flaws across domains. The next experiment must address that gap before a result section or publication-style effect estimate is justified.
