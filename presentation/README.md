# Research update presentation

The eight-slide deck explains the current research in plain English to an
audience new to AI and cybersecurity. It is designed for a 5–6 minute talk.

Start with the [one-minute explanation](START_HERE.md) before presenting.

- [Editable PowerPoint](Research_Update_2026-11-01.pptx)
- [PDF for presenting](Research_Update_2026-11-01.pdf)
- [Contact sheet](Research_Update_Contact_Sheet.png)
- [Speaker notes and source links](SPEAKER_NOTES.md)

All figures and cards in the PowerPoint are editable shapes. Speaker notes are
embedded in the PowerPoint and duplicated in the Markdown file. The source
deck is generated by `build_research_update.py`; `render_preview.py` creates
the contact sheet and individual slide PNGs from the PDF.

The 40 archived agent episodes, authored calibration cases, excluded pilot,
and proposed main experiment are labeled separately. The deck claims only the
historical test–gate disagreement. It does not claim a causal agent effect or
general security of code that passed finite tests.
