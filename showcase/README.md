# November 2026 research showcase

The [submission package](2026-11-08/README.md) contains a one-page landscape
poster, title plus five content slides, a 131-word abstract, editable PowerPoints,
and a group speaking script with Q&A preparation.

Team: Imran Zakirov and Iosifova Nuriya. Mentor and active project contributor:
Kramich Anna. These showcase roles do not automatically amend manuscript authorship.

The public-facing title is **The Tests Passed. The Grader Said No.**
It presents the historical finite-test/acceptance audit in plain language.

Build with `python -B -m showcase.build_showcase`, export the PPTX files to PDF,
then run `python -B -m showcase.validate_showcase` using the bundled workspace
Python and LibreOffice. The generated package is prepared for user review;
it has not been submitted to the organizers.
