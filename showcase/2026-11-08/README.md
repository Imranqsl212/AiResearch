# Комплект для Research Showcase

**Тема:** The Tests Passed. The Grader Said No.

**Команда:** Imran Zakirov, Iosifova Nuriya.

**Ментор и активный участник проекта:** Kramich Anna.

Все материалы подготовлены на английском. Имена сохранены в присланном вами
написании. Представление команды в showcase не меняет автоматически авторский
список существующей рукописи.

## Что отправить организаторам

Один участник отправляет материалы за весь проект:

1. Данные из [SUBMISSION_DETAILS.txt](SUBMISSION_DETAILS.txt): название, имена,
   ментор, abstract и необязательные ссылки.
2. [Постер PDF](Zakirov_Iosifova_AI_Checker_Audit_Poster.pdf): **одна страница,
   горизонтальный формат 16:9**. Есть вопрос, background, methods, results,
   conclusion, next steps, references и график 9/20.
3. [Слайды PDF](Zakirov_Iosifova_AI_Checker_Audit_Slides.pdf): **титул + пять
   основных слайдов**. Это файл для общего deck организаторов.

Срок из вашего чек-листа: **воскресенье, 8 ноября 2026, 12:00 дня по Бишкеку
(UTC+6)**. Пакет подготовлен локально; отправка организаторам не выполнена.
Если форма просит отдельные файлы, загрузите именно два PDF, а не только ZIP.
Если будут присланы дополнительные правила именования, переименуйте файлы по ним.

репетицию с таймером. Если Анна не выступает, в файле речи есть распределение
её части между двумя студентами. Организаторы переключают слайды: говорите
“Next slide, please.” Камера должна быть включена.

## Проверка готовности

- [x] Название, участники, ментор и его двойная роль указаны.
- [x] Abstract короче 150 слов.
- [x] Постер: один горизонтальный лист 16:9, все требуемые разделы.
- [x] Презентация: титул и не более пяти основных слайдов.
- [x] Есть визуальные материалы, реальный пример, трудности и выводы.
- [x] Числа связаны с сохранёнными результатами, границы выводов указаны.
- [ ] Участники прочитали материалы и подтвердили, что понимают их.
- [ ] Проведена реальная репетиция с таймером.
- [ ] Один участник отправил комплект до срока.

Необязательно пересказывать все эксперименты: основной рассказ посвящён
проверенному историческому результату **9/20**, а небольшие новые пилоты
упомянуты как предварительные. Showcase допускает незавершённые исследования.

## Пересборка

Из корня репозитория запустите `python -B -m showcase.build_showcase` с bundled
workspace Python, затем экспортируйте два PPTX в PDF через LibreOffice или
PowerPoint. Исходный файл — `showcase/build_showcase.py`; метаданные находятся
в `metadata.json`. Содержание прежней статьи и старой презентации не заменяется.
