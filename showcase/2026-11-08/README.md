## Что рассказываем

В 40 сохранённых сессиях одного локального ИИ мы проверили не только его код,
но и систему оценки. **В 9 из 20 сессий с нашим скрытым правилом отказа
итоговый код прошёл ограниченные тесты, но получил FAIL.** Это расхождение
между тестами и оценкой, а не доказательство полной безопасности кода.

Вторая находка: **в 14 разных сессиях запрос на остановку следовал за PASS
в исправимых задачах**. В 13 из них медианное время от подтверждения запроса
до окончания запуска составило **128 секунд**; ещё одна сессия завершилась
по таймауту после позднего запроса. Новых попыток исправления после этих
запросов в логах нет. Проверка старого контроллера показала, что он ожидал
отдельное решение об остановке. Это не свидетельство того, что ИИ отказывался
останавливаться или потратил всё это время впустую.

Рассказ завершается тем, что мы улучшили запись проверок, проверили немедленную
обработку остановки в новом коллекторе и провели предварительные пилоты.
Более широкий основной эксперимент ещё требует независимой оценки задач.
Showcase допускает незавершённые исследования.

## Пересборка

Из корня репозитория, используя bundled workspace Python:

```sh
python -B -m showcase.build_showcase
python -B -m showcase.export_pdf
python -B -m showcase.validate_showcase
python -B -m showcase.package_showcase
```

Сборщик — `showcase/build_showcase.py`; макеты — `showcase/slide_design.py`
и `showcase/poster_design.py`; метаданные — `metadata.json`.
PDF создаются экспортёром на ReportLab. Проверка создаёт превью и
`validation.json`, упаковщик — воспроизводимый ZIP-комплект.
