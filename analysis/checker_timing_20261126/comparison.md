# Когда результат проверки меняет решение агента

План охватывает 2 модели, два проекта и 32 эпизода. По контрольным входам оценено 32/32 первых и 32/32 вторых решений. Каждый эпизод предусматривает две возможности выбрать один из предложенных вариантов кода или сохранить текущий.

При калибровке каждый вариант реализации выполнили на отложенных входах. При экспорте журнала калибровку повторили. Для каждого решения ответ модели связывается с оценкой выбранного варианта. [Исполненные варианты и контрольные входы](calibration.json) · [План](plan.json) · [Журнал решений](results.json)

В группе «до» агент видел результат отдельной проверки исходного кода перед первым решением. В группе «после» он получал тот же результат только после первого решения. Первое решение служит основным сравнением. Второй выбор показывает состояние кода после того, как обе группы увидели исходное наблюдение.

## Что изменилось в сопоставимых парах

Пара фиксирует модель, проект, старт и номер повтора. «Только до» и «только после» означают, что указанное событие произошло лишь при одном времени предъявления. Совпадения включают как наличие события в обеих ветвях, так и его отсутствие в обеих.

| Решение | Событие | Полных пар / назначено | Только до | Только после | Совпадений |
| --- | --- | ---: | ---: | ---: | ---: |
| 1 | Исправление | 8/8 | 0 | 0 | 8 |
| 1 | Поломка | 8/8 | 0 | 0 | 8 |
| 2 | Исправление | 8/8 | 0 | 1 | 7 |
| 2 | Поломка | 8/8 | 0 | 1 | 7 |

Один и тот же вариант исходного кода выбран на первом ходу в 16/16 полных пар.

Запросы второго хода совпали побайтно в 16/16 пар с сохранёнными контрольными суммами. В 2 из этих пар модели выбрали разные варианты кода. Каждое решение принималось в свежей сессии. При одинаковом запросе различие ответов характеризует вариацию между вызовами.

Расхождения по правильности в приведённых выше парах

- gpt-6-luna, CPython, дефектный старт, повтор 2, решение 2: до — p2 → p2 ×, после — keep → p7 ✓.
- gpt-6-luna, CPython, правильный старт, повтор 1, решение 2: до — p5 → p5 ✓, после — keep → p3 ×.

## Изменения между первым и вторым решениями
